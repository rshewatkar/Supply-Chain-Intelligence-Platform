### Endpoints Implemented (8 Total)

**AI Chat Interface (2 endpoints):**
1. POST `/chat/query` - Main AI chat interface with question routing
   - Calls: ChatAssistant.ask()
   - Returns: Routed answer based on detected intent

2. POST `/chat/detect-intent` - Intent detection only
   - Calls: ChatAssistant.router.route()
   - Returns: intent, confidence score

**Direct Graph Queries (6 endpoints):**
3. GET `/chat/suppliers/{company_name}` - Get suppliers
   - Calls: GraphQueries.get_suppliers()
   - Param: limit (1-100, default 20)

4. GET `/chat/common-suppliers/{company_1}/{company_2}` - Get shared suppliers
   - Calls: GraphQueries.get_common_suppliers()
   - Param: limit (1-100, default 20)

5. GET `/chat/dependency-metrics/{company_name}` - Get dependency analysis
   - Calls: GraphQueries.get_dependency_metrics()

6. GET `/chat/tier2-dependencies/{company_name}` - Get indirect suppliers
   - Calls: GraphQueries.get_tier2_dependencies()
   - Param: limit (1-100, default 20)

7. GET `/chat/relationships/{entity_name}` - Get all relationships
   - Calls: GraphQueries.get_supply_chain_relationships()
   - Param: limit (1-100, default 30)

8. GET `/chat/entities` - Search entities by name
   - Calls: GraphQueries.find_entities()
   - Params: search_term (string), limit (1-100, default 10)
